FASE 0 - SETUP INICIAL                                              [ALL] ~2-4h
--------------------------------------------------------------------------------
Objetivo: preparar a solucao .NET e o projeto Angular.

Backend (por ordem):
  1) backend/NzolaNet.sln + os 4 *.csproj (criar solucao e referencias)
  2) backend/NzolaNet.Api/appsettings.json  (connection string SQL Server + JWT)
  3) backend/NzolaNet.Api/Properties/launchSettings.json  (porta, ex.: 5000)

  Comandos (a partir de backend/):
    dotnet new sln -n NzolaNet
    dotnet new webapi   -n NzolaNet.Api
    dotnet new classlib -n NzolaNet.Application
    dotnet new classlib -n NzolaNet.Domain
    dotnet new classlib -n NzolaNet.Infrastructure
    (referencias: Api->Application, Application->Domain, Infrastructure->Application+Domain)
    NuGet: EFCore.SqlServer, EFCore.Tools, JwtBearer, BCrypt.Net-Next,
           AutoMapper, FluentValidation, Swashbuckle

Frontend:
    ng new nzolanet --style=scss --routing=true
    instalar: TailwindCSS ou Bootstrap, ngx-toastr, date-fns, jwt-decode

TESTAR:
  - Backend: "dotnet build" compila sem erros.
  - Frontend: "ng serve" abre http://localhost:4200.
