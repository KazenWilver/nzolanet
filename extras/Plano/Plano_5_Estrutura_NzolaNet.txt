### **DTOs Principais**

#### **Auth**
- `UserRegisterDTO`: `Username`, `Email`, `Password`, `ConfirmPassword`
- `UserLoginDTO`: `Email`, `Password`
- `AuthResponseDTO`: `Token`, `Expiration`, `UserDTO`
- `ForgotPasswordDTO`: `Email`
- `ResetPasswordDTO`: `Token`, `NewPassword`, `ConfirmPassword`

#### **User**
- `UserDTO`: `Id`, `Username`, `Email`, `ProfilePicture`, `IsPrivate`, `IsAdmin`
- `UserProfileDTO`: `UserDTO` + `Bio`, `FollowerCount`, `FollowingCount`, `PostCount`, `IsFollowing` (booleano para o utilizador atual)
- `UserUpdateDTO`: `Username`, `Bio`, `IsPrivate`

#### **Post**
- `PostDTO`: `Id`, `UserId`, `Username`, `UserProfilePicture`, `Text`, `ImageUrl`, `VideoUrl`, `CreatedAt`, `LikeCount`, `CommentCount`, `IsLikedByCurrentUser`
- `PostCreateDTO`: `Text`, `Image` (IFormFile), `Video` (IFormFile)
- `PostUpdateDTO`: `Text`, `Image` (IFormFile), `Video` (IFormFile)

#### **Comment**
- `CommentDTO`: `Id`, `PostId`, `UserId`, `Username`, `UserProfilePicture`, `Text`, `CreatedAt`, `IsEditable` (booleano para o utilizador atual)
- `CommentCreateDTO`: `Text`
- `CommentUpdateDTO`: `Text`

#### **Like**
- `LikeDTO`: `Id`, `PostId`, `UserId`, `CreatedAt`

#### **Notification**
- `NotificationDTO`: `Id`, `Type` (Like/Comment/Follow), `FromUserId`, `FromUsername`, `FromProfilePicture`, `PostId`, `PostText`, `IsRead`, `CreatedAt`

#### **Feed**
- Usa `PostDTO` com ordenação por `CreatedAt DESC`

### **Regras de Autorização**
| **Ação**               | **Permissão**                          |
|------------------------|----------------------------------------|
| Criar/Editar/Apagar Publicação | Apenas dono da publicação             |
| Criar/Editar/Apagar Comentário  | Apenas dono do comentário ou admin    |
| Dar/Remover "Baze"      | Qualquer utilizador autenticado       |
| Seguir/Deixar de Seguir | Qualquer utilizador autenticado       |
| Ver Perfil Privado      | Apenas dono ou seguidores              |
| Remover Comentário      | Apenas admin                           |

---

### **Códigos de Status HTTP**
- **200 OK**: Sucesso em requisições GET/PUT/DELETE
- **201 Created**: Sucesso em requisições POST (ex: criar publicação)
- **400 Bad Request**: Dados inválidos (validação de DTOs)
- **401 Unauthorized**: Token ausente ou inválido
- **403 Forbidden**: Utilizador sem permissão (ex: editar publicação de outro)
- **404 Not Found**: Recurso não encontrado
- **409 Conflict**: Conflito (ex: já deu "baze" nesta publicação)
- **500 Internal Server Error**: Erro no servidor

# **🔌 Serviços (Core)**

## **`AuthService`**
```typescript
@Injectable({ providedIn: 'root' })
export class AuthService {
  constructor(private http: HttpClient, private router: Router) {}
  
  login(data: UserLoginDTO): Observable<AuthResponseDTO> { ... }
  register(data: UserRegisterDTO): Observable<UserDTO> { ... }
  logout(): void { ... }
  forgotPassword(email: string): Observable<MessageDTO> { ... }
  resetPassword(data: ResetPasswordDTO): Observable<MessageDTO> { ... }
  getCurrentUser(): Observable<UserProfileDTO> { ... }
```

## **`PostOwnerGuard`**
```typescript
@Injectable({ providedIn: 'root' })
export class PostOwnerGuard implements CanActivate {
  constructor(private postService: PostService, private authService: AuthService) {}
  
  async canActivate(route: ActivatedRouteSnapshot): Promise<boolean> {
    const postId = route.params.id;
    const post = await this.postService.getPostById(postId).toPromise();
    const currentUserId = this.authService.getCurrentUserId();
    if (post?.userId === currentUserId) return true;
    this.router.navigate(['/feed']);
    return false;
  }
}
```

# **🔄 Interceptores**

## **`JwtInterceptor`**
```typescript
@Injectable()
export class JwtInterceptor implements HttpInterceptor {
  constructor(private authService: AuthService) {}
  
  intercept(req: HttpRequest<any>, next: HttpHandler): Observable<HttpEvent<any>> {
    const token = this.authService.getToken();
    if (token) {
      req = req.clone({
        setHeaders: { Authorization: `Bearer ${token}` }
      });
    }
    return next.handle(req);
  }
}
```

## **`ErrorInterceptor`**
```typescript
@Injectable()
export class ErrorInterceptor implements HttpInterceptor {
  constructor(private router: Router, private toastService: ToastService) {}
  
  intercept(req: HttpRequest<any>, next: HttpHandler): Observable<HttpEvent<any>> {
    return next.handle(req).pipe(
      catchError((error: HttpErrorResponse) => {
        switch (error.status) {
          case 401:
            this.router.navigate(['/login']);
            break;
          case 403:
            this.toastService.error('Não tem permissão para esta ação.');
            break;
          case 404:
            this.toastService.error('Recurso não encontrado.');
            break;
          default:
            this.toastService.error('Ocorreu um erro. Tente novamente.');
        }
        return throwError(() => error);
      })
    );
  }
}
```

# **🎯 Boas Práticas para 20/20**

## **✅ Organização**
- **Módulos por feature**: Cada funcionalidade (auth, user, posts) tem o seu módulo com lazy loading.
- **Componentes reutilizáveis**: `PostCard`, `UserCard`, `Modal`, etc. são compartilhados.
- **Serviços centralizados**: Todos os serviços HTTP estão em `core/services/`.
- **Separação de responsabilidades**: Cada serviço lida com uma entidade (ex: `PostService` apenas para publicações).

## **✅ Clean Code**
- **Nomes descritivos**: `getPostsByUser()` em vez de `getUserPosts()`.
- **Funções pequenas**: Cada função faz uma coisa só (ex: `login()` apenas faz login, não valida formulário).
- **Tipagem forte**: Usar interfaces para todos os DTOs (ex: `PostDTO` em vez de `any`).
- **RxJS**: Usar `Observable` e `pipe` para manipular dados de forma reativa.

## **✅ Performance**
- **Lazy Loading**: Módulos são carregados apenas quando necessários.
- **TrackBy em *ngFor**: Evitar re-render desnecessário de listas.
- **OnPush Change Detection**: Usar `ChangeDetectionStrategy.OnPush` em componentes que não precisam de deteção de mudanças frequente.
- **Unsubscribe de Observables**: Usar `takeUntil` ou `async pipe` para evitar memory leaks.

## **✅ UI/UX**
- **Responsivo**: Usar CSS Grid/Flexbox e media queries.
- **Feedback visual**: Spinners durante carregamento, toasts para erros/sucessos.
- **Acessibilidade**: Alt text em imagens, ARIA labels, teclado navegável.
- **Consistência**: Mesma paleta de cores, tipografia, espaçamento.

## **✅ Segurança**
- **Sanitização**: Usar `DomSanitizer` para conteúdo HTML (ex: vídeos).
- **Validação**: Validar inputs no frontend (mas **sempre** validar no backend também).
- **Token seguro**: Armazenar JWT em `localStorage` (ou `sessionStorage` para sessões curtas).

## **✅ Testes (Opcional para 20/20)**
- **Testes unitários**: Jasmine/Karma para componentes e serviços.
- **Testes E2E**: Protractor ou Cypress para fluxos completos (ex: login → criar post).

   - Mostrar mensagens de erro **amigáveis** ao utilizador (ex: "Publicação não encontrada" em vez de "Error 404").

   - Usar `ReactiveFormsModule` e `FormGroup`/`FormControl`.

   - Mostrar erros de validação em tempo real.

   - Validar tipo (apenas `.jpg`, `.png`, `.mp4`).
   - Validar tamanho (ex: max 10MB).

   - Comprimir imagens no frontend (usar `ngx-image-compress`).

   - Implementar **scroll infinito** ou paginação.

     - Novo post de um seguidor.

   - Testar em mobile, tablet e desktop.

   - Adicionar `alt` a todas as imagens.

    - Comentar código complexo.

# **🔄 AutoMapper (Mapeamento entre Entidades e DTOs)**

## **`AutoMapperProfile.cs`**
```csharp
public class AutoMapperProfile : Profile
{
    public AutoMapperProfile()
    {
        // User
        CreateMap<User, UserDTO>();
        CreateMap<User, UserProfileDTO>()
            .ForMember(dest => dest.FollowerCount, opt => opt.MapFrom(src => src.Followers.Count))
            .ForMember(dest => dest.FollowingCount, opt => opt.MapFrom(src => src.Following.Count))
            .ForMember(dest => dest.PostCount, opt => opt.MapFrom(src => src.Posts.Count))
            .ForMember(dest => dest.IsFollowing, opt => opt.Ignore()); // Preenchido no serviço
        
        // Post
        CreateMap<Post, PostDTO>()
            .ForMember(dest => dest.Username, opt => opt.MapFrom(src => src.User.Username))
            .ForMember(dest => dest.UserProfilePicture, opt => opt.MapFrom(src => src.User.ProfilePicture))
            .ForMember(dest => dest.LikeCount, opt => opt.MapFrom(src => src.Likes.Count))
            .ForMember(dest => dest.CommentCount, opt => opt.MapFrom(src => src.Comments.Count))
            .ForMember(dest => dest.IsLikedByCurrentUser, opt => opt.Ignore()); // Preenchido no serviço
        
        CreateMap<Post, PostListDTO>()
            .ForMember(dest => dest.Username, opt => opt.MapFrom(src => src.User.Username))
            .ForMember(dest => dest.UserProfilePicture, opt => opt.MapFrom(src => src.User.ProfilePicture));
        
        CreateMap<PostCreateDTO, Post>()
            .ForMember(dest => dest.UserId, opt => opt.Ignore()) // Preenchido no serviço
            .ForMember(dest => dest.ImageUrl, opt => opt.Ignore()) // Preenchido no upload
            .ForMember(dest => dest.VideoUrl, opt => opt.Ignore()); // Preenchido no upload
        
        // Comment
        CreateMap<Comment, CommentDTO>()
            .ForMember(dest => dest.Username, opt => opt.MapFrom(src => src.User.Username))
            .ForMember(dest => dest.UserProfilePicture, opt => opt.MapFrom(src => src.User.ProfilePicture))
            .ForMember(dest => dest.IsEditable, opt => opt.Ignore()); // Preenchido no serviço
        
        CreateMap<CommentCreateDTO, Comment>()
            .ForMember(dest => dest.PostId, opt => opt.Ignore()) // Preenchido no serviço
            .ForMember(dest => dest.UserId, opt => opt.Ignore()); // Preenchido no serviço
        
        // Like
        CreateMap<Like, LikeDTO>();
        
        // Notification
        CreateMap<Notification, NotificationDTO>()
            .ForMember(dest => dest.FromUsername, opt => opt.MapFrom(src => src.FromUser.Username))
            .ForMember(dest => dest.FromProfilePicture, opt => opt.MapFrom(src => src.FromUser.ProfilePicture))
            .ForMember(dest => dest.PostText, opt => opt.MapFrom(src => src.Post != null ? src.Post.Text[..Math.Min(src.Post.Text.Length, 50)] : null));
        
        // Follow
        CreateMap<Follow, FollowDTO>();
    }
}
```

```csharp
public class PostRepository : IPostRepository
{
    private readonly NzolaNetDbContext _context;
    
    public PostRepository(NzolaNetDbContext context)
    {
        _context = context;
    }
    
    public async Task<Post?> GetByIdAsync(int id)
    {
        return await _context.Posts
            .Include(p => p.User)
            .Include(p => p.Likes)
            .Include(p => p.Comments)
            .FirstOrDefaultAsync(p => p.Id == id);
    }
    
    public async Task<IEnumerable<Post>> GetByUserIdAsync(int userId)
    {
        return await _context.Posts
            .Where(p => p.UserId == userId)
            .Include(p => p.User)
            .Include(p => p.Likes)
            .Include(p => p.Comments)
            .OrderByDescending(p => p.CreatedAt)
            .ToListAsync();
    }
    
    public async Task<PagedResult<Post>> GetAllAsync(int pageNumber, int pageSize)
    {
        var totalCount = await _context.Posts.CountAsync();
        var posts = await _context.Posts
            .Include(p => p.User)
            .Include(p => p.Likes)
            .Include(p => p.Comments)
            .OrderByDescending(p => p.CreatedAt)
            .Skip((pageNumber - 1) * pageSize)
            .Take(pageSize)
            .ToListAsync();
        
        return new PagedResult<Post>(posts, totalCount, pageNumber, pageSize);
    }
    
    public async Task<PagedResult<Post>> GetFeedAsync(int userId, int pageNumber, int pageSize)
    {
        // Publicações de utilizadores seguidos + próprias
        var followingIds = await _context.Follows
            .Where(f => f.FollowerId == userId)
            .Select(f => f.FollowingId)
            .ToListAsync();
        
        var userIds = followingIds.Append(userId); // Incluir próprias publicações
        
        var totalCount = await _context.Posts
            .Where(p => userIds.Contains(p.UserId) && !p.User.IsPrivate)
            .CountAsync();
        
        var posts = await _context.Posts
            .Where(p => userIds.Contains(p.UserId) && !p.User.IsPrivate)
            .Include(p => p.User)
            .Include(p => p.Likes)
            .Include(p => p.Comments)
            .OrderByDescending(p => p.CreatedAt)
            .Skip((pageNumber - 1) * pageSize)
            .Take(pageSize)
            .ToListAsync();
        
        return new PagedResult<Post>(posts, totalCount, pageNumber, pageSize);
    }
    
    public void Add(Post post)
    {
        _context.Posts.Add(post);
    }
    
    public void Update(Post post)
    {
        _context.Posts.Update(post);
    }
    
    public void Delete(Post post)
    {
        _context.Posts.Remove(post);
    }
    
    public async Task<bool> ExistsAsync(int id)
    {
        return await _context.Posts.AnyAsync(p => p.Id == id);
    }
}
```

```csharp
public class AuthService : IAuthService
{
    private readonly IUserRepository _userRepository;
    private readonly IConfiguration _configuration;
    private readonly IMapper _mapper;

    public async Task<AuthResponseDTO> Register(UserRegisterDTO registerDTO)
    {
        if (await _userRepository.ExistsAsync(registerDTO.Email, registerDTO.Username))
        {
            throw new ConflictException("Email ou username já existem.");
        }
        
        CreatePasswordHash(registerDTO.Password, out byte[] passwordHash, out byte[] passwordSalt);
        
        var user = new User
        {
            Username = registerDTO.Username,
            Email = registerDTO.Email,
            PasswordHash = passwordHash,
            PasswordSalt = passwordSalt
        };
        
        _userRepository.Add(user);
        await _unitOfWork.SaveChangesAsync();
        
        var token = GenerateJwtToken(user);
        return new AuthResponseDTO
        {
            Token = token,
            Expiration = DateTime.UtcNow.AddHours(1),
            User = _mapper.Map<UserDTO>(user)
        };
    }
    
    public async Task<AuthResponseDTO> Login(UserLoginDTO loginDTO)
    {
        var user = await _userRepository.GetByEmailAsync(loginDTO.Email);
        if (user == null || !VerifyPasswordHash(loginDTO.Password, user.PasswordHash, user.PasswordSalt))
        {
            throw new UnauthorizedException("Email ou senha inválidos.");
        }
        
        var token = GenerateJwtToken(user);
        return new AuthResponseDTO
        {
            Token = token,
            Expiration = DateTime.UtcNow.AddHours(1),
            User = _mapper.Map<UserDTO>(user)
        };
    }
    
    public async Task<MessageDTO> ForgotPassword(ForgotPasswordDTO forgotPasswordDTO)
    {
        var user = await _userRepository.GetByEmailAsync(forgotPasswordDTO.Email);
        if (user == null)
        {
            // Não revelar se o email existe ou não (por segurança)
            return new MessageDTO { Message = "Se o email existir, será enviado um link de recuperação.", Success = true };
        }
        
        // Gerar token temporário (em produção, enviar email com link)
        var token = GenerateResetToken();
        // TODO: Salvar token na BD (tabela PasswordResetTokens) e enviar email
        
        return new MessageDTO { Message = "Link de recuperação enviado para o email.", Success = true };
    }
    
    public async Task<MessageDTO> ResetPassword(ResetPasswordDTO resetPasswordDTO)
    {
        // TODO: Validar token e encontrar utilizador
        var user = await _userRepository.GetByEmailAsync("email@exemplo.com"); // Buscar pelo token
        if (user == null)
        {
            throw new BadRequestException("Token inválido ou expirado.");
        }
        
        CreatePasswordHash(resetPasswordDTO.NewPassword, out byte[] passwordHash, out byte[] passwordSalt);
        user.PasswordHash = passwordHash;
        user.PasswordSalt = passwordSalt;
        
        _userRepository.Update(user);
        await _unitOfWork.SaveChangesAsync();
        
        return new MessageDTO { Message = "Senha redefinida com sucesso.", Success = true };
    }
    
    private void CreatePasswordHash(string password, out byte[] passwordHash, out byte[] passwordSalt)
    {
        using var hmac = new HMACSHA256();
        passwordSalt = hmac.Key;
        passwordHash = hmac.ComputeHash(Encoding.UTF8.GetBytes(password));
    }
    
    private bool VerifyPasswordHash(string password, byte[] storedHash, byte[] storedSalt)
    {
        using var hmac = new HMACSHA256(storedSalt);
        var computedHash = hmac.ComputeHash(Encoding.UTF8.GetBytes(password));
        return computedHash.SequenceEqual(storedHash);
    }
    
    private string GenerateJwtToken(User user)
    {
        var securityKey = new SymmetricSecurityKey(Encoding.UTF8.GetBytes(_configuration["Jwt:Key"]));
        var credentials = new SigningCredentials(securityKey, SecurityAlgorithms.HmacSha256);
        
        var claims = new List<Claim>
        {
            new Claim(ClaimTypes.NameIdentifier, user.Id.ToString()),
            new Claim(ClaimTypes.Name, user.Username),
            new Claim(ClaimTypes.Email, user.Email),
            new Claim(ClaimTypes.Role, user.IsAdmin ? "Admin" : "User")
        };
        
        var token = new JwtSecurityToken(
            issuer: _configuration["Jwt:Issuer"],
            audience: _configuration["Jwt:Audience"],
            claims: claims,
            expires: DateTime.UtcNow.AddHours(1),
            signingCredentials: credentials
        );
        
        return new JwtSecurityTokenHandler().WriteToken(token);
    }
    
    private string GenerateResetToken()
    {
        var randomNumber = new byte[32];
        using var rng = RandomNumberGenerator.Create();
        rng.GetBytes(randomNumber);
        return Convert.ToBase64String(randomNumber);
    }
```

```csharp
public class StorageService : IStorageService
{
    private readonly IWebHostEnvironment _environment;
    
    public StorageService(IWebHostEnvironment environment)
    {
        _environment = environment;
    }
    
    public async Task<string> UploadFileAsync(IFormFile file, string folderName)
    {
        // Validar tipo e tamanho
        if (file == null || file.Length == 0)
        {
            throw new BadRequestException("Ficheiro inválido.");
        }
        
        var allowedExtensions = new[] { ".jpg", ".jpeg", ".png", ".mp4" };
        var extension = Path.GetExtension(file.FileName).ToLowerInvariant();
        if (!allowedExtensions.Contains(extension))
        {
            throw new BadRequestException("Tipo de ficheiro não suportado.");
        }
        
        const long maxFileSize = 10 * 1024 * 1024; // 10MB
        if (file.Length > maxFileSize)
        {
            throw new BadRequestException("Ficheiro demasiado grande (máx. 10MB).");
        }
        
        // Criar pasta se não existir
        var uploadsFolder = Path.Combine(_environment.WebRootPath, "uploads", folderName);
        Directory.CreateDirectory(uploadsFolder);
        
        // Gerar nome único para o ficheiro
        var fileName = $"{Guid.NewGuid()}{extension}";
        var filePath = Path.Combine(uploadsFolder, fileName);
        
        // Salvar ficheiro
        using (var stream = new FileStream(filePath, FileMode.Create))
        {
            await file.CopyToAsync(stream);
        }
        
        // Retornar URL relativa
        return $"/uploads/{folderName}/{fileName}";
    }
    
    public async Task DeleteFileAsync(string fileUrl)
    {
        if (string.IsNullOrEmpty(fileUrl))
        {
            return;
        }
        
        var filePath = Path.Combine(_environment.WebRootPath, fileUrl.TrimStart('/'));
        if (File.Exists(filePath))
        {
            File.Delete(filePath);
        }
    }
}
```

```csharp
// PostOwnerRequirement.cs
public class PostOwnerRequirement : IAuthorizationRequirement { }

// PostOwnerHandler.cs
public class PostOwnerHandler : AuthorizationHandler<PostOwnerRequirement>
{
    private readonly IPostRepository _postRepository;
    private readonly IHttpContextAccessor _httpContextAccessor;
    
    public PostOwnerHandler(IPostRepository postRepository, IHttpContextAccessor httpContextAccessor)
    {
        _postRepository = postRepository;
        _httpContextAccessor = httpContextAccessor;
    }
    
    protected override async Task HandleRequirementAsync(
        AuthorizationHandlerContext context,
        PostOwnerRequirement requirement)
    {
        // Obter o ID do post da rota (ex: /api/posts/{id})
        var routeData = _httpContextAccessor.HttpContext?.Request.RouteValues;
        if (routeData == null || !routeData.TryGetValue("id", out var idObj) || !int.TryParse(idObj?.ToString(), out int postId))
        {
            context.Fail();
            return;
        }
        
        var post = await _postRepository.GetByIdAsync(postId);
        if (post == null)
        {
            context.Fail();
            return;
        }
        
        // Obter o ID do utilizador atual
        var userIdClaim = context.User.FindFirst(ClaimTypes.NameIdentifier);
        if (userIdClaim == null || !int.TryParse(userIdClaim.Value, out int userId))
        {
            context.Fail();
            return;
        }
        
        // Verificar se o utilizador é o dono do post
        if (post.UserId == userId)
        {
            context.Succeed(requirement);
        }
        else
        {
            context.Fail();
        }
    }
}
```

```csharp
        var adminEmail = "admin@nzolanet.com";
        var adminExists = await _userRepository.GetByEmailAsync(adminEmail);
        if (adminExists == null)
        {

            };
            
            _userRepository.Add(admin);

        }

    }
```

# **🛡️ Middleware (Tratamento de Exceções)**

## **`ExceptionMiddleware.cs`**
```csharp
public class ExceptionMiddleware
{
    private readonly RequestDelegate _next;
    private readonly ILogger<ExceptionMiddleware> _logger;
    
    public ExceptionMiddleware(RequestDelegate next, ILogger<ExceptionMiddleware> logger)
    {
        _next = next;
        _logger = logger;
    }
    
    public async Task InvokeAsync(HttpContext httpContext)
    {
        try
        {
            await _next(httpContext);
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "Ocorreu um erro não tratado.");
            await HandleExceptionAsync(httpContext, ex);
        }
    }
    
    private Task HandleExceptionAsync(HttpContext context, Exception exception)
    {
        context.Response.ContentType = "application/json";
        context.Response.StatusCode = (int)HttpStatusCode.InternalServerError;
        
        var response = new MessageDTO
        {
            Message = "Ocorreu um erro interno. Tente novamente mais tarde.",
            Success = false
        };
        
        // Tratar exceções conhecidas
        switch (exception)
        {
            case NotFoundException notFound:
                context.Response.StatusCode = (int)HttpStatusCode.NotFound;
                response.Message = notFound.Message;
                break;
            case BadRequestException badRequest:
                context.Response.StatusCode = (int)HttpStatusCode.BadRequest;
                response.Message = badRequest.Message;
                break;
            case UnauthorizedException unauthorized:
                context.Response.StatusCode = (int)HttpStatusCode.Unauthorized;
                response.Message = unauthorized.Message;
                break;
            case ForbiddenException forbidden:
                context.Response.StatusCode = (int)HttpStatusCode.Forbidden;
                response.Message = forbidden.Message;
                break;
            case ConflictException conflict:
                context.Response.StatusCode = (int)HttpStatusCode.Conflict;
                response.Message = conflict.Message;
                break;
            case ValidationException validation:
                context.Response.StatusCode = (int)HttpStatusCode.BadRequest;
                response.Message = string.Join("; ", validation.Errors);
                break;
        }
        
        return context.Response.WriteAsync(JsonSerializer.Serialize(response));
    }
}
```

```csharp
public class UnitOfWork : IUnitOfWork
{
    private readonly NzolaNetDbContext _context;
    
    public UnitOfWork(NzolaNetDbContext context)
    {
        _context = context;
    }
    
    public async Task<int> SaveChangesAsync()
    {
        // Atualizar campos UpdatedAt automaticamente
        var entries = _context.ChangeTracker.Entries<BaseEntity>();
        foreach (var entry in entries)
        {
            if (entry.State == EntityState.Modified)
            {
                entry.Entity.UpdatedAt = DateTime.UtcNow;
            }
        }
        
        return await _context.SaveChangesAsync();
    }
    
    public void Dispose()
    {
        _context.Dispose();
    }
}
```

- **Swagger/OpenAPI**: Documentar todos os endpoints.

## **🛡️ Regras para Evitar Conflitos**

### **✅ DO (FAÇA)**
1. **Sincronize sempre antes de começar a trabalhar:**
   ```bash
   git checkout develop
   git pull origin develop
   ```
2. **Trabalhe em branches separadas** (nunca diretamente em `develop` ou `main`).
3. **Faça commits frequentes** (pequenas mudanças são mais fáceis de rever).
4. **Use `.gitignore` corretamente:**
   - Backend: `bin/`, `obj/`, `appsettings.Development.json`
   - Frontend: `node_modules/`, `dist/`, `.angular/`
5. **Teste o seu código localmente** antes de fazer PR.
6. **Comunique-se com o grupo** antes de fazer mudanças grandes (ex: alterar estrutura de pastas).
7. **Use `git pull --rebase`** para atualizar a sua branch:
   ```bash
   git checkout feature/minha-feature
   git pull --rebase origin develop
   ```
8. **Resolva conflitos localmente** antes de fazer push.
9. **Adicione o `CONTRIBUTING.md`** ao repositório para que todos sigam as mesmas regras.

### **❌ DON'T (NÃO FAÇA)**
1. **Nunca faça commit em `main` ou `develop`** (sempre use branches).
2. **Nunca faça `git push --force`** (a menos que seja absolutamente necessário e avisado ao grupo).
3. **Não trabalhe em features grandes sem dividir** (ex: não faça tudo em `feature/frontend`; divida em `feature/frontend-auth`, `feature/frontend-posts`, etc.).
4. **Não ignore os testes** (se o código quebra um teste, corrija-o antes de fazer PR).
5. **Não faça merge de PRs sem revisão** (sempre peça a outro membro para rever).
6. **Não comite código que não funciona** (teste antes de fazer commit).
7. **Não apague branches de outros membros** (apenas o dono da branch pode apagar).
8. **Não use mensagens de commit vagas** como "fix", "update", "changes" (seja específico).

## **🔄 Estratégia de Resolução de Conflitos**

### **1. Conflito ao Fazer `git pull`**
- **Sintoma:**
  ```
  error: You have unmerged paths.
  ```
- **Solução:**
  ```bash
  # Ver quais ficheiros têm conflito
  git status
  
  # Abrir os ficheiros com conflito e resolver manualmente
  # (Procurar por <<<<<<<, =======, >>>>>>>)
  
  # Após resolver:
  git add [ficheiro]
  git commit -m "resolve: merge conflict in [ficheiro]"
  ```

### **2. Conflito ao Fazer Merge no GitHub**
- **Sintoma:** GitHub mostra "This branch has conflicts that must be resolved".
- **Solução:**
  1. Fazer pull da branch de destino:
     ```bash
     git checkout develop
     git pull origin develop
     ```
  2. Fazer checkout da sua branch e merge com develop:
     ```bash
     git checkout feature/minha-feature
     git merge develop
     ```
  3. Resolver conflitos localmente (como acima).
  4. Fazer push:
     ```bash
     git push origin feature/minha-feature
     ```
  5. O GitHub vai atualizar o PR automaticamente.

### **3. Conflito em Ficheiros Binários (ex: imagens)**
- **Solução:**
  - **Evitar:** Não editar os mesmos ficheiros binários em branches diferentes.
  - **Se acontecer:**
    ```bash
    # Manter a versão da branch de destino
    git checkout --ours [ficheiro]
    # Ou manter a versão da sua branch
    git checkout --theirs [ficheiro]
    ```

## **📊 Boas Práticas para Trabalho em Grupo**

### **1. Comunicação**
- **Reuniões diárias (stand-up):** 15 minutos para alinhar progresso e bloqueios.
- **Canal de comunicação:** WhatsApp, Telegram ou Discord para dúvidas rápidas.
- **Documentar decisões:** Adicionar ao `CONTRIBUTING.md` ou `docs/meeting-notes/`.

### **2. Divisão de Tarefas**
- **Usar GitHub Projects** ou **Trello** para gerir tasks.
- **Tarefas pequenas:** Dividir features grandes em tasks menores (ex: "Criar endpoint de login" em vez de "Fazer autenticação").
- **Assign tasks:** Cada task deve ter um responsável claro.

### **3. Code Review Eficaz**
- **Revisar cedo:** Não esperar até o final para fazer code review.
- **Focar em:**
  - **Corretude:** O código faz o que deve?
  - **Segurança:** Há vulnerabilidades?
  - **Performance:** Há gargalos?
  - **Legibilidade:** O código é fácil de entender?
- **Comentar de forma construtiva:**
  - ❌ "Isso está errado."
  - ✅ "Aqui, a validação do email não está a funcionar porque falta o `@`. Podemos usar `EmailAddressAttribute`."

### **4. Integração Contínua**
- **Testar localmente:** Antes de fazer PR, testar:
  - Backend: API com Postman/Swagger.
  - Frontend: App Angular com `ng serve`.
  - Integração: Frontend consumindo API local.
- **Usar variáveis de ambiente:**
  - Backend: `appsettings.Development.json` para configurações de desenvolvimento.
  - Frontend: `environment.ts` para URLs da API.

### **5. Backup e Recuperação**
- **Fazer backup das branches importantes:**
  ```bash
  git branch backup/feature/minha-feature
  ```
- **Recuperar código apagado:**
  ```bash
  git reflog
  git checkout -b recovered-branch [commit-hash]
  ```

**Exemplo: `AuthService`**
```typescript
@Injectable({ providedIn: 'root' })
export class AuthService {
  private readonly API_URL = environment.apiUrl;
  private readonly TOKEN_KEY = 'nzolanet_token';

  constructor(private http: HttpClient, private router: Router) {}

  login(data: UserLoginDTO): Observable<AuthResponseDTO> {
    return this.http.post<AuthResponseDTO>(`${this.API_URL}/auth/login`, data).pipe(
      tap((res) => {
        localStorage.setItem(this.TOKEN_KEY, res.token);
      })
    );
  }

  register(data: UserRegisterDTO): Observable<AuthResponseDTO> {
    return this.http.post<AuthResponseDTO>(`${this.API_URL}/auth/register`, data);
  }

  logout(): void {
    localStorage.removeItem(this.TOKEN_KEY);
    this.router.navigate(['/login']);
  }

  getToken(): string | null {
    return localStorage.getItem(this.TOKEN_KEY);
  }

  isAuthenticated(): boolean {
    return !!this.getToken();
  }
}
```

## **🚦 GUARDS (Proteção de Rotas)**
| **Guard**               | **Finalidade**                                                                                     | **Implementação**                                                                                     |
|-------------------------|---------------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------|
| `AuthGuard`             | Bloqueia rotas para utilizadores não autenticados                                              | Verifica se `AuthService.isAuthenticated()` é `true`                                               |
| `AdminGuard`           | Apenas permite acesso a admin                                                                     | Verifica se o utilizador tem `isAdmin: true`                                                       |
| `PostOwnerGuard`       | Apenas permite editar/apagar publicações do dono                                                 | Verifica se o ID do utilizador atual = ID do dono da publicação                                   |
| `PrivateProfileGuard`  | Bloqueia acesso a perfis privados para não seguidores                                           | Verifica se o perfil é público **OU** o utilizador atual segue o dono do perfil                  |

---
**Exemplo: `AuthGuard`**
```typescript
@Injectable({ providedIn: 'root' })
export class AuthGuard implements CanActivate {
  constructor(private authService: AuthService, private router: Router) {}

  canActivate(): boolean {
    if (this.authService.isAuthenticated()) {
      return true;
    }
    this.router.navigate(['/login']);
    return false;
  }
}
```

## **🔄 INTERCEPTORS (Manipulação de Requests)**
| **Interceptor**       | **Finalidade**                                                                                     |
|------------------------|---------------------------------------------------------------------------------------------------|
| `JwtInterceptor`      | Adiciona o token JWT ao header `Authorization` de todos os requests                              |
| `ErrorInterceptor`    | Trata erros globais (401, 403, 404, 500) e mostra mensagens de erro ao utilizador                     |

---
**Exemplo: `JwtInterceptor`**
```typescript
@Injectable()
export class JwtInterceptor implements HttpInterceptor {
  constructor(private authService: AuthService) {}

  intercept(req: HttpRequest<any>, next: HttpHandler): Observable<HttpEvent<any>> {
    const token = this.authService.getToken();
    if (token) {
      req = req.clone({
        setHeaders: { Authorization: `Bearer ${token}` }
      });
    }
    return next.handle(req);
  }
}
```

## **🎯 BOAS PRÁTICAS PARA 20/20 (Frontend)**
### **✅ Organização**
- **Módulos por feature**: Cada funcionalidade (auth, user, posts) tem o seu módulo com **lazy loading**.
- **Componentes reutilizáveis**: `PostCard`, `UserCard`, `Modal`, etc. são compartilhados em `shared/`.
- **Serviços centralizados**: Todos os serviços HTTP estão em `core/services/`.
- **Separação de responsabilidades**: Cada serviço lida com uma entidade (ex: `PostService` apenas para publicações).

### **✅ Clean Code**
- **Nomes descritivos**: `getPostsByUser()` em vez de `getUserPosts()`.
- **Funções pequenas**: Cada função faz uma coisa só.
- **Tipagem forte**: Usar interfaces para todos os DTOs (evitar `any`).
- **RxJS**: Usar `Observable` e `pipe` para manipular dados de forma reativa.

### **✅ Performance**
- **Lazy Loading**: Módulos são carregados apenas quando necessários.
- **TrackBy em *ngFor**: Evitar re-render desnecessário de listas.
  ```html
  <div *ngFor="let post of posts; trackBy: trackByPostId">
  ```
  ```typescript
  trackByPostId(index: number, post: PostDTO): number {
    return post.id;
  }
  ```
- **OnPush Change Detection**: Usar `ChangeDetectionStrategy.OnPush` em componentes que não precisam de deteção de mudanças frequente.
- **Unsubscribe de Observables**: Usar `takeUntil` ou `async pipe` para evitar memory leaks.
  ```typescript
  private destroy$ = new Subject<void>();

  ngOnInit() {
    this.postService.getPosts().pipe(
      takeUntil(this.destroy$)
    ).subscribe(posts => this.posts = posts);
  }

  ngOnDestroy() {
    this.destroy$.next();
    this.destroy$.complete();
  }
  ```

### **✅ UI/UX**
- **Responsivo**: Usar **CSS Grid/Flexbox** e **media queries**.
  ```scss
  @media (max-width: 768px) {
    // Estilos para mobile
  }
  ```
- **Feedback visual**: Spinners durante carregamento, toasts para erros/sucessos.
- **Acessibilidade**: Alt text em imagens, ARIA labels, teclado navegável.
- **Consistência**: Mesma paleta de cores, tipografia, espaçamento.

### **✅ Segurança**
- **Sanitização**: Usar `DomSanitizer` para conteúdo HTML (ex: vídeos).
  ```typescript
  constructor(private sanitizer: DomSanitizer) {}

  getSafeUrl(url: string) {
    return this.sanitizer.bypassSecurityTrustResourceUrl(url);
  }
  ```
- **Validação**: Validar inputs no frontend (mas **sempre validar no backend também**).
- **Token seguro**: Armazenar JWT em `localStorage` (ou `sessionStorage` para sessões curtas).

### **✅ Upload de Ficheiros**
- **Validação**:
  - Tipo: apenas `.jpg`, `.png`, `.mp4`.
  - Tamanho: max 10MB.
- **Preview**: Mostrar preview da imagem/vídeo antes de submeter.
- **Compressão**: Usar `ngx-image-compress` para compressão de imagens.
  ```typescript
  import { NgxImageCompressService } from 'ngx-image-compress';

  constructor(private imageCompress: NgxImageCompressService) {}

  async compressImage(file: File): Promise<File> {
    const compressedImage = await this.imageCompress.compressFile(file, Orientation.Up, 50, 50);
    return new File([compressedImage], file.name, { type: 'image/jpeg' });
  }
  ```

### **✅ Feed Dinâmico**
- **Scroll infinito**: Usar `ngx-infinite-scroll`.
  ```html
  <div infiniteScroll [infiniteScrollDistance]="2" [infiniteScrollThrottle]="50" (scrolled)="loadMore()">
    <app-post-card *ngFor="let post of posts" [post]="post"></app-post-card>
  </div>
  ```
- **Atualização em tempo real**:
  - **Opcional 1**: Polling (requisição a cada 30s).
    ```typescript
    interval(30000).pipe(
      takeUntil(this.destroy$)
    ).subscribe(() => this.feedService.getFeed().subscribe(feed => this.posts = feed));
    ```
  - **Opcional 2 (para 20/20)**: SignalR (WebSockets) para notificações em tempo real.

### **✅ Notificações**
- **Contagem no sino**: Atualizar em tempo real (usar `BehaviorSubject`).
  ```typescript
  // notification.service.ts
  private unreadCount$ = new BehaviorSubject<number>(0);
  unreadCount = this.unreadCount$.asObservable();

  constructor() {
    this.startPolling();
  }

  private startPolling() {
    interval(30000).pipe(
      takeUntil(this.destroy$)
    ).subscribe(() => {
      this.getUnreadCount().subscribe(count => this.unreadCount$.next(count));
    });
  }
  ```
- **Marcar como lida**: Ao clicar na notificação ou no sino.

### **✅ Privacidade de Perfis**
- Se `isPrivate: true` e o utilizador atual **não é seguidor**:
  - Esconder publicações.
  - Mostrar mensagem: *"Este perfil é privado. Siga para ver publicações."*

## **🗃️ BASE DE DADOS (SQL SERVER)**
### **Diagrama Entidade-Relacionamento (ER)**
**Ver: [Diagrama ER](canvas:nzolanet-er-diagram)**

### **Tabelas e Relacionamentos**
| **Tabela**       | **Campos**                                                                                     | **Relacionamentos**                                                                                     |
|------------------|-----------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------|
| **Users**        | `Id (PK)`, `Username`, `Email`, `PasswordHash`, `PasswordSalt`, `ProfilePicture`, `Bio`, `IsPrivate`, `IsAdmin`, `CreatedAt`, `UpdatedAt` | 1:N → Posts, Comments, Likes, Follows (Follower), Follows (Following), Notifications |
| **Posts**        | `Id (PK)`, `UserId (FK)`, `Text`, `ImageUrl`, `VideoUrl`, `CreatedAt`, `UpdatedAt`              | N:1 → User, 1:N → Comments, Likes                                                                       |
| **Comments**     | `Id (PK)`, `PostId (FK)`, `UserId (FK)`, `Text`, `IsDeleted`, `CreatedAt`, `UpdatedAt`         | N:1 → Post, User                                                                                       |
| **Likes**        | `Id (PK)`, `PostId (FK)`, `UserId (FK)`, `CreatedAt`                                         | N:1 → Post, User, **Unique (PostId + UserId)** (impedir múltiplos likes)                              |
| **Follows**      | `Id (PK)`, `FollowerId (FK)`, `FollowingId (FK)`, `CreatedAt`                                | N:1 → User (Follower), User (Following), **Unique (FollowerId + FollowingId)**                         |
| **Notifications**| `Id (PK)`, `UserId (FK)`, `Type (Like/Comment/Follow)`, `FromUserId (FK)`, `PostId (FK)`, `IsRead`, `CreatedAt` | N:1 → User, User (FromUser), Post (opcional)                                                          |

### **Script SQL para Criação das Tabelas**
```sql
-- Tabela de Utilizadores
CREATE TABLE Users (
    Id INT PRIMARY KEY IDENTITY(1,1),
    Username NVARCHAR(50) NOT NULL UNIQUE,
    Email NVARCHAR(100) NOT NULL UNIQUE,
    PasswordHash VARBINARY(255) NOT NULL,
    PasswordSalt VARBINARY(255) NOT NULL,
    ProfilePicture NVARCHAR(255) NULL,
    Bio NVARCHAR(500) NULL,
    IsPrivate BIT DEFAULT 0,
    IsAdmin BIT DEFAULT 0,
    CreatedAt DATETIME2 DEFAULT GETUTCDATE(),
    UpdatedAt DATETIME2 DEFAULT GETUTCDATE()
);

-- Tabela de Publicações
CREATE TABLE Posts (
    Id INT PRIMARY KEY IDENTITY(1,1),
    UserId INT NOT NULL,
    Text NVARCHAR(MAX) NOT NULL,
    ImageUrl NVARCHAR(255) NULL,
    VideoUrl NVARCHAR(255) NULL,
    CreatedAt DATETIME2 DEFAULT GETUTCDATE(),
    UpdatedAt DATETIME2 DEFAULT GETUTCDATE(),
    CONSTRAINT FK_Posts_Users FOREIGN KEY (UserId) REFERENCES Users(Id) ON DELETE CASCADE
);

-- Tabela de Comentários
CREATE TABLE Comments (
    Id INT PRIMARY KEY IDENTITY(1,1),
    PostId INT NOT NULL,
    UserId INT NOT NULL,
    Text NVARCHAR(MAX) NOT NULL,
    IsDeleted BIT DEFAULT 0,
    CreatedAt DATETIME2 DEFAULT GETUTCDATE(),
    UpdatedAt DATETIME2 DEFAULT GETUTCDATE(),
    CONSTRAINT FK_Comments_Posts FOREIGN KEY (PostId) REFERENCES Posts(Id) ON DELETE CASCADE,
    CONSTRAINT FK_Comments_Users FOREIGN KEY (UserId) REFERENCES Users(Id) ON DELETE CASCADE
);

-- Tabela de "Bazes" (Likes)
CREATE TABLE Likes (
    Id INT PRIMARY KEY IDENTITY(1,1),
    PostId INT NOT NULL,
    UserId INT NOT NULL,
    CreatedAt DATETIME2 DEFAULT GETUTCDATE(),
    CONSTRAINT FK_Likes_Posts FOREIGN KEY (PostId) REFERENCES Posts(Id) ON DELETE CASCADE,
    CONSTRAINT FK_Likes_Users FOREIGN KEY (UserId) REFERENCES Users(Id) ON DELETE CASCADE,
    CONSTRAINT UQ_Likes_PostUser UNIQUE (PostId, UserId) -- Impede múltiplos likes do mesmo user no mesmo post
);

-- Tabela de Seguidores
CREATE TABLE Follows (
    Id INT PRIMARY KEY IDENTITY(1,1),
    FollowerId INT NOT NULL,
    FollowingId INT NOT NULL,
    CreatedAt DATETIME2 DEFAULT GETUTCDATE(),
    CONSTRAINT FK_Follows_Follower FOREIGN KEY (FollowerId) REFERENCES Users(Id) ON DELETE CASCADE,
    CONSTRAINT FK_Follows_Following FOREIGN KEY (FollowingId) REFERENCES Users(Id) ON DELETE CASCADE,
    CONSTRAINT UQ_Follows_FollowerFollowing UNIQUE (FollowerId, FollowingId) -- Impede seguir o mesmo user mais de uma vez
);

-- Tabela de Notificações
CREATE TABLE Notifications (
    Id INT PRIMARY KEY IDENTITY(1,1),
    UserId INT NOT NULL,
    Type NVARCHAR(20) NOT NULL, -- 'Like', 'Comment', 'Follow'
    FromUserId INT NOT NULL,
    PostId INT NULL,
    IsRead BIT DEFAULT 0,
    CreatedAt DATETIME2 DEFAULT GETUTCDATE(),
    CONSTRAINT FK_Notifications_Users FOREIGN KEY (UserId) REFERENCES Users(Id) ON DELETE CASCADE,
    CONSTRAINT FK_Notifications_FromUser FOREIGN KEY (FromUserId) REFERENCES Users(Id) ON DELETE CASCADE,
    CONSTRAINT FK_Notifications_Posts FOREIGN KEY (PostId) REFERENCES Posts(Id) ON DELETE CASCADE
);

-- Índices para performance
CREATE INDEX IX_Posts_UserId ON Posts(UserId);
CREATE INDEX IX_Comments_PostId ON Comments(PostId);
CREATE INDEX IX_Comments_UserId ON Comments(UserId);
CREATE INDEX IX_Likes_PostId ON Likes(PostId);
CREATE INDEX IX_Likes_UserId ON Likes(UserId);
CREATE INDEX IX_Follows_FollowerId ON Follows(FollowerId);
CREATE INDEX IX_Follows_FollowingId ON Follows(FollowingId);
CREATE INDEX IX_Notifications_UserId ON Notifications(UserId);
CREATE INDEX IX_Notifications_IsRead ON Notifications(IsRead);
```

## **🔄 AUTO MAPPER (Mapeamento entre Entidades e DTOs)**
**Localização:** `NzolaNet.Api/DTOs/Mappers/AutoMapperProfile.cs`

```csharp
public class AutoMapperProfile : Profile
{
    public AutoMapperProfile()
    {
        // User
        CreateMap<User, UserDTO>();
        CreateMap<User, UserProfileDTO>()
            .ForMember(dest => dest.FollowerCount, opt => opt.MapFrom(src => src.Followers.Count))
            .ForMember(dest => dest.FollowingCount, opt => opt.MapFrom(src => src.Following.Count))
            .ForMember(dest => dest.PostCount, opt => opt.MapFrom(src => src.Posts.Count))
            .ForMember(dest => dest.IsFollowing, opt => opt.Ignore()); // Preenchido no serviço

        // Post
        CreateMap<Post, PostDTO>()
            .ForMember(dest => dest.Username, opt => opt.MapFrom(src => src.User.Username))
            .ForMember(dest => dest.UserProfilePicture, opt => opt.MapFrom(src => src.User.ProfilePicture))
            .ForMember(dest => dest.LikeCount, opt => opt.MapFrom(src => src.Likes.Count))
            .ForMember(dest => dest.CommentCount, opt => opt.MapFrom(src => src.Comments.Count))
            .ForMember(dest => dest.IsLikedByCurrentUser, opt => opt.Ignore());

        CreateMap<PostCreateDTO, Post>()
            .ForMember(dest => dest.UserId, opt => opt.Ignore()) // Preenchido no serviço
            .ForMember(dest => dest.ImageUrl, opt => opt.Ignore()) // Preenchido no upload
            .ForMember(dest => dest.VideoUrl, opt => opt.Ignore());

        // Comment
        CreateMap<Comment, CommentDTO>()
            .ForMember(dest => dest.Username, opt => opt.MapFrom(src => src.User.Username))
            .ForMember(dest => dest.UserProfilePicture, opt => opt.MapFrom(src => src.User.ProfilePicture))
            .ForMember(dest => dest.IsEditable, opt => opt.Ignore());

        CreateMap<CommentCreateDTO, Comment>()
            .ForMember(dest => dest.PostId, opt => opt.Ignore())
            .ForMember(dest => dest.UserId, opt => opt.Ignore());

        // Like
        CreateMap<Like, LikeDTO>();

        // Notification
        CreateMap<Notification, NotificationDTO>()
            .ForMember(dest => dest.FromUsername, opt => opt.MapFrom(src => src.FromUser.Username))
            .ForMember(dest => dest.FromProfilePicture, opt => opt.MapFrom(src => src.FromUser.ProfilePicture))
            .ForMember(dest => dest.PostText, opt => opt.MapFrom(src =>
                src.Post != null ? src.Post.Text[..Math.Min(src.Post.Text.Length, 50)] : null));

        // Follow
        CreateMap<Follow, FollowDTO>();
    }
}
```

```csharp
public class PostRepository : IPostRepository
{
    private readonly NzolaNetDbContext _context;

    public PostRepository(NzolaNetDbContext context) => _context = context;

    public async Task<Post?> GetByIdAsync(int id) => await _context.Posts
        .Include(p => p.User)
        .Include(p => p.Likes)
        .Include(p => p.Comments)
        .FirstOrDefaultAsync(p => p.Id == id);

    public async Task<IEnumerable<Post>> GetByUserIdAsync(int userId) => await _context.Posts
        .Where(p => p.UserId == userId)
        .Include(p => p.User)
        .Include(p => p.Likes)
        .Include(p => p.Comments)
        .OrderByDescending(p => p.CreatedAt)
        .ToListAsync();

    public async Task<PagedResult<Post>> GetAllAsync(int pageNumber, int pageSize)
    {
        var totalCount = await _context.Posts.CountAsync();
        var posts = await _context.Posts
            .Include(p => p.User)
            .Include(p => p.Likes)
            .Include(p => p.Comments)
            .OrderByDescending(p => p.CreatedAt)
            .Skip((pageNumber - 1) * pageSize)
            .Take(pageSize)
            .ToListAsync();
        return new PagedResult<Post>(posts, totalCount, pageNumber, pageSize);
    }

    public async Task<PagedResult<Post>> GetFeedAsync(int userId, int pageNumber, int pageSize)
    {
        // Publicações de utilizadores seguidos + próprias
        var followingIds = await _context.Follows
            .Where(f => f.FollowerId == userId)
            .Select(f => f.FollowingId)
            .ToListAsync();

        var userIds = followingIds.Append(userId); // Incluir próprias publicações

        var totalCount = await _context.Posts
            .Where(p => userIds.Contains(p.UserId) && !p.User.IsPrivate)
            .CountAsync();

        var posts = await _context.Posts
            .Where(p => userIds.Contains(p.UserId) && !p.User.IsPrivate)
            .Include(p => p.User)
            .Include(p => p.Likes)
            .Include(p => p.Comments)
            .OrderByDescending(p => p.CreatedAt)
            .Skip((pageNumber - 1) * pageSize)
            .Take(pageSize)
            .ToListAsync();

        return new PagedResult<Post>(posts, totalCount, pageNumber, pageSize);
    }

    public void Add(Post post) => _context.Posts.Add(post);
    public void Update(Post post) => _context.Posts.Update(post);
    public void Delete(Post post) => _context.Posts.Remove(post);
    public async Task<bool> ExistsAsync(int id) => await _context.Posts.AnyAsync(p => p.Id == id);
```

```csharp
public class AuthService : IAuthService
{
    private readonly IUserRepository _userRepository;
    private readonly IConfiguration _configuration;
    private readonly IMapper _mapper;

    public AuthService(IUserRepository userRepository, IConfiguration configuration, IMapper mapper)
    {
        _userRepository = userRepository;
        _configuration = configuration;
        _mapper = mapper;
    }

    public async Task<AuthResponseDTO> Register(UserRegisterDTO registerDTO)
    {
        if (await _userRepository.ExistsAsync(registerDTO.Email, registerDTO.Username))
            throw new ConflictException("Email ou username já existem.");

        CreatePasswordHash(registerDTO.Password, out byte[] passwordHash, out byte[] passwordSalt);

        var user = new User
        {
            Username = registerDTO.Username,
            Email = registerDTO.Email,
            PasswordHash = passwordHash,
            PasswordSalt = passwordSalt
        };

        _userRepository.Add(user);
        await _unitOfWork.SaveChangesAsync();

        var token = GenerateJwtToken(user);
        return new AuthResponseDTO
        {
            Token = token,
            Expiration = DateTime.UtcNow.AddHours(1),
            User = _mapper.Map<UserDTO>(user)
        };
    }

    public async Task<AuthResponseDTO> Login(UserLoginDTO loginDTO)
    {
        var user = await _userRepository.GetByEmailAsync(loginDTO.Email);
        if (user == null || !VerifyPasswordHash(loginDTO.Password, user.PasswordHash, user.PasswordSalt))
            throw new UnauthorizedException("Email ou senha inválidos.");

        var token = GenerateJwtToken(user);
        return new AuthResponseDTO
        {
            Token = token,
            Expiration = DateTime.UtcNow.AddHours(1),
            User = _mapper.Map<UserDTO>(user)
        };
    }

    private void CreatePasswordHash(string password, out byte[] passwordHash, out byte[] passwordSalt)
    {
        using var hmac = new HMACSHA256();
        passwordSalt = hmac.Key;
        passwordHash = hmac.ComputeHash(Encoding.UTF8.GetBytes(password));
    }

    private bool VerifyPasswordHash(string password, byte[] storedHash, byte[] storedSalt)
    {
        using var hmac = new HMACSHA256(storedSalt);
        var computedHash = hmac.ComputeHash(Encoding.UTF8.GetBytes(password));
        return computedHash.SequenceEqual(storedHash);
    }

    private string GenerateJwtToken(User user)
    {
        var securityKey = new SymmetricSecurityKey(Encoding.UTF8.GetBytes(_configuration["Jwt:Key"]));
        var credentials = new SigningCredentials(securityKey, SecurityAlgorithms.HmacSha256);

        var claims = new List<Claim>
        {
            new Claim(ClaimTypes.NameIdentifier, user.Id.ToString()),
            new Claim(ClaimTypes.Name, user.Username),
            new Claim(ClaimTypes.Email, user.Email),
            new Claim(ClaimTypes.Role, user.IsAdmin ? "Admin" : "User")
        };

        var token = new JwtSecurityToken(
            issuer: _configuration["Jwt:Issuer"],
            audience: _configuration["Jwt:Audience"],
            claims: claims,
            expires: DateTime.UtcNow.AddHours(1),
            signingCredentials: credentials
        );

        return new JwtSecurityTokenHandler().WriteToken(token);
    }
}
```

```csharp
public class UserService : IUserService
{
    private readonly IUserRepository _userRepository;
    private readonly IFollowRepository _followRepository;
    private readonly IStorageService _storageService;
    private readonly IMapper _mapper;
    private readonly IHttpContextAccessor _httpContextAccessor;
    private readonly INotificationService _notificationService;

    public UserService(
        IUserRepository userRepository,
        IFollowRepository followRepository,
        IStorageService storageService,
        IMapper mapper,
        IHttpContextAccessor httpContextAccessor,
        INotificationService notificationService)
    {
        _userRepository = userRepository;
        _followRepository = followRepository;
        _storageService = storageService;
        _mapper = mapper;
        _httpContextAccessor = httpContextAccessor;
        _notificationService = notificationService;
    }

    public async Task<UserProfileDTO> GetUserById(int id)
    {
        var currentUserId = GetCurrentUserId();
        var user = await _userRepository.GetByIdAsync(id);
        if (user == null) throw new NotFoundException("Utilizador não encontrado.");

        // Verificar privacidade do perfil
        if (user.IsPrivate && user.Id != currentUserId)
        {
            var isFollowing = await _userRepository.IsFollowingAsync(currentUserId, user.Id);
            if (!isFollowing) throw new ForbiddenException("Este perfil é privado.");
        }

        var userProfile = _mapper.Map<UserProfileDTO>(user);
        userProfile.IsFollowing = await _userRepository.IsFollowingAsync(currentUserId, user.Id);
        return userProfile;
    }

    public async Task<UserProfileDTO> UpdateUser(int id, UserUpdateDTO updateDTO)
    {
        var currentUserId = GetCurrentUserId();
        if (id != currentUserId) throw new ForbiddenException("Apenas pode editar o seu próprio perfil.");

        var user = await _userRepository.GetByIdAsync(id);
        if (user == null) throw new NotFoundException("Utilizador não encontrado.");

        if (updateDTO.Username != null) user.Username = updateDTO.Username;
        if (updateDTO.Bio != null) user.Bio = updateDTO.Bio;
        if (updateDTO.IsPrivate.HasValue) user.IsPrivate = updateDTO.IsPrivate.Value;

        user.UpdatedAt = DateTime.UtcNow;
        _userRepository.Update(user);
        await _unitOfWork.SaveChangesAsync();

        return _mapper.Map<UserProfileDTO>(user);
    }

    public async Task<UserProfileDTO> UpdateProfilePicture(int id, IFormFile file)
    {
        var currentUserId = GetCurrentUserId();
        if (id != currentUserId) throw new ForbiddenException("Apenas pode editar a sua própria foto.");

        var user = await _userRepository.GetByIdAsync(id);
        if (user == null) throw new NotFoundException("Utilizador não encontrado.");

        // Apagar foto antiga (se existir)
        if (!string.IsNullOrEmpty(user.ProfilePicture))
            await _storageService.DeleteFileAsync(user.ProfilePicture);

        // Upload da nova foto
        var imageUrl = await _storageService.UploadFileAsync(file, "profile-pictures");
        user.ProfilePicture = imageUrl;
        user.UpdatedAt = DateTime.UtcNow;

        _userRepository.Update(user);
        await _unitOfWork.SaveChangesAsync();

        return _mapper.Map<UserProfileDTO>(user);
    }

    public async Task<FollowDTO> FollowUser(int followingId)
    {
        var currentUserId = GetCurrentUserId();
        if (currentUserId == followingId) throw new BadRequestException("Não pode seguir a si próprio.");

        var user = await _userRepository.GetByIdAsync(followingId);
        if (user == null) throw new NotFoundException("Utilizador não encontrado.");

        // Verificar se já segue
        var existingFollow = await _followRepository.GetByFollowerAndFollowingAsync(currentUserId, followingId);
        if (existingFollow != null) throw new ConflictException("Já segue este utilizador.");

        var follow = new Follow { FollowerId = currentUserId, FollowingId = followingId };
        _followRepository.Add(follow);
        await _unitOfWork.SaveChangesAsync();

        // Criar notificação para o utilizador seguido
        await _notificationService.CreateNotification(
            user.Id,
            NotificationType.Follow,
            currentUserId,
            null
        );

        return _mapper.Map<FollowDTO>(follow);
    }

    public async Task<MessageDTO> UnfollowUser(int followingId)
    {
        var currentUserId = GetCurrentUserId();
        var follow = await _followRepository.GetByFollowerAndFollowingAsync(currentUserId, followingId);
        if (follow == null) throw new NotFoundException("Não está a seguir este utilizador.");

        _followRepository.Delete(follow);
        await _unitOfWork.SaveChangesAsync();

        return new MessageDTO { Message = "Deixou de seguir o utilizador.", Success = true };
    }

    private int GetCurrentUserId()
    {
        var userIdClaim = _httpContextAccessor.HttpContext?.User.FindFirst(ClaimTypes.NameIdentifier);
        if (userIdClaim == null || !int.TryParse(userIdClaim.Value, out int userId))
            throw new UnauthorizedException("Utilizador não autenticado.");
        return userId;
    }
}
```

```csharp
        string? videoUrl = null;

        if (createDTO.Image != null)
            imageUrl = await _storageService.UploadFileAsync(createDTO.Image, "post-images");
        if (createDTO.Video != null)
            videoUrl = await _storageService.UploadFileAsync(createDTO.Video, "post-videos");

        var post = new Post
        {
            UserId = currentUserId,
            Text = createDTO.Text,
            ImageUrl = imageUrl,
            VideoUrl = videoUrl
        };

        _postRepository.Add(post);
        await _unitOfWork.SaveChangesAsync();

        var postDTO = _mapper.Map<PostDTO>(post);
        postDTO.IsLikedByCurrentUser = false;
        return postDTO;
    }

        await _unitOfWork.SaveChangesAsync();
```

```csharp
public class StorageService : IStorageService
{
    private readonly IWebHostEnvironment _environment;

    public StorageService(IWebHostEnvironment environment) => _environment = environment;

    public async Task<string> UploadFileAsync(IFormFile file, string folderName)
    {
        // Validar tipo e tamanho
        if (file == null || file.Length == 0)
            throw new BadRequestException("Ficheiro inválido.");

        var allowedExtensions = new[] { ".jpg", ".jpeg", ".png", ".mp4" };
        var extension = Path.GetExtension(file.FileName).ToLowerInvariant();
        if (!allowedExtensions.Contains(extension))
            throw new BadRequestException("Tipo de ficheiro não suportado.");

        const long maxFileSize = 10 * 1024 * 1024; // 10MB
        if (file.Length > maxFileSize)
            throw new BadRequestException("Ficheiro demasiado grande (máx. 10MB).");

        // Criar pasta se não existir
        var uploadsFolder = Path.Combine(_environment.WebRootPath, "uploads", folderName);
        Directory.CreateDirectory(uploadsFolder);

        // Gerar nome único para o ficheiro
        var fileName = $"{Guid.NewGuid()}{extension}";
        var filePath = Path.Combine(uploadsFolder, fileName);

        // Salvar ficheiro
        using (var stream = new FileStream(filePath, FileMode.Create))
            await file.CopyToAsync(stream);

        // Retornar URL relativa
        return $"/uploads/{folderName}/{fileName}";
    }

    public async Task DeleteFileAsync(string fileUrl)
    {
        if (string.IsNullOrEmpty(fileUrl)) return;
        var filePath = Path.Combine(_environment.WebRootPath, fileUrl.TrimStart('/'));
        if (File.Exists(filePath)) File.Delete(filePath);
    }
}
```

```csharp
// PostOwnerRequirement.cs
public class PostOwnerRequirement : IAuthorizationRequirement { }

// PostOwnerHandler.cs
public class PostOwnerHandler : AuthorizationHandler<PostOwnerRequirement>
{
    private readonly IPostRepository _postRepository;
    private readonly IHttpContextAccessor _httpContextAccessor;

    public PostOwnerHandler(IPostRepository postRepository, IHttpContextAccessor httpContextAccessor)
    {
        _postRepository = postRepository;
        _httpContextAccessor = httpContextAccessor;
    }

    protected override async Task HandleRequirementAsync(
        AuthorizationHandlerContext context,
        PostOwnerRequirement requirement)
    {
        var routeData = _httpContextAccessor.HttpContext?.Request.RouteValues;
        if (routeData == null || !routeData.TryGetValue("id", out var idObj) || !int.TryParse(idObj?.ToString(), out int postId))
        {
            context.Fail();
            return;
        }

        var post = await _postRepository.GetByIdAsync(postId);
        if (post == null)
        {
            context.Fail();
            return;
        }

        var userIdClaim = context.User.FindFirst(ClaimTypes.NameIdentifier);
        if (userIdClaim == null || !int.TryParse(userIdClaim.Value, out int userId))
        {
            context.Fail();
            return;
        }

        if (post.UserId == userId)
            context.Succeed(requirement);
        else
            context.Fail();
    }
}
```

### **`ExceptionMiddleware.cs`**
```csharp
public class ExceptionMiddleware
{
    private readonly RequestDelegate _next;
    private readonly ILogger<ExceptionMiddleware> _logger;

    public ExceptionMiddleware(RequestDelegate next, ILogger<ExceptionMiddleware> logger)
    {
        _next = next;
        _logger = logger;
    }

    public async Task InvokeAsync(HttpContext httpContext)
    {
        try
        {
            await _next(httpContext);
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "Ocorreu um erro não tratado.");
            await HandleExceptionAsync(httpContext, ex);
        }
    }

    private Task HandleExceptionAsync(HttpContext context, Exception exception)
    {
        context.Response.ContentType = "application/json";
        context.Response.StatusCode = (int)HttpStatusCode.InternalServerError;

        var response = new MessageDTO
        {
            Message = "Ocorreu um erro interno. Tente novamente mais tarde.",
            Success = false
        };

        switch (exception)
        {
            case NotFoundException notFound:
                context.Response.StatusCode = (int)HttpStatusCode.NotFound;
                response.Message = notFound.Message;
                break;
            case BadRequestException badRequest:
                context.Response.StatusCode = (int)HttpStatusCode.BadRequest;
                response.Message = badRequest.Message;
                break;
            case UnauthorizedException unauthorized:
                context.Response.StatusCode = (int)HttpStatusCode.Unauthorized;
                response.Message = unauthorized.Message;
                break;
            case ForbiddenException forbidden:
                context.Response.StatusCode = (int)HttpStatusCode.Forbidden;
                response.Message = forbidden.Message;
                break;
            case ConflictException conflict:
                context.Response.StatusCode = (int)HttpStatusCode.Conflict;
                response.Message = conflict.Message;
                break;
            case ValidationException validation:
                context.Response.StatusCode = (int)HttpStatusCode.BadRequest;
                response.Message = string.Join("; ", validation.Errors);
                break;
        }

        return context.Response.WriteAsync(JsonSerializer.Serialize(response));
    }
}
```

```csharp
public class UnitOfWork : IUnitOfWork
{
    private readonly NzolaNetDbContext _context;

    public UnitOfWork(NzolaNetDbContext context) => _context = context;

    public async Task<int> SaveChangesAsync()
    {
        // Atualizar campos UpdatedAt automaticamente
        var entries = _context.ChangeTracker.Entries<BaseEntity>();
        foreach (var entry in entries)
        {
            if (entry.State == EntityState.Modified)
                entry.Entity.UpdatedAt = DateTime.UtcNow;
        }
        return await _context.SaveChangesAsync();
    }

    public void Dispose() => _context.Dispose();
}
```

## **✅ BOAS PRÁTICAS PARA EVITAR CONFLITOS**
### **FAÇA:**
1. **Sincronize sempre antes de começar:**
   ```bash
   git checkout develop
   git pull origin develop
   ```
2. **Trabalhe em branches separadas** (nunca em `develop` ou `main`).
3. **Faça commits frequentes** (pequenas mudanças são mais fáceis de rever).
4. **Use `.gitignore` corretamente** (ver [Estratégia Git](canvas:nzolanet-git-strategy)).
5. **Teste o seu código localmente** antes de fazer PR.
6. **Comunique-se com o grupo** antes de fazer mudanças grandes.
7. **Use `git pull --rebase`** para atualizar a sua branch:
   ```bash
   git checkout feature/minha-feature
   git pull --rebase origin develop
   ```
8. **Resolva conflitos localmente** antes de fazer push.

### **NÃO FAÇA:**
1. **Nunca faça commit em `main` ou `develop`** (sempre use branches).
2. **Nunca faça `git push --force`** (a menos que seja absolutamente necessário e avisado ao grupo).
3. **Não trabalhe em features grandes sem dividir** (ex: `feature/frontend` → divida em `feature/frontend-auth`, `feature/frontend-posts`).
4. **Não ignore os testes** (se o código quebra um teste, corrija-o antes de fazer PR).
5. **Não faça merge de PRs sem revisão** (sempre peça a outro membro para rever).
6. **Não comite código que não funciona** (teste antes de fazer commit).
